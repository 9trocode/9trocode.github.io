# About

I'm **Alex Idowu**, a Cloud Infrastructure and Software Engineer based in Lagos, Nigeria. I build deployment platforms, open source infra tools, and security systems — and write about what actually works in production.

## Work

I'm **Founder & CTO at [PipeOps](https://pipeops.io)** ([PipeOpsHQ](https://github.com/PipeOpsHQ)), a cloud deployment platform that abstracts DevOps complexity so teams can go from code to cloud in minutes. We focus on multi-cloud provisioning, Kubernetes-based runtime, and making platform engineering usable for startups and engineers who shouldn't need a full DevOps team.

I'm also building **Aeon** — security software for high-trust organizations (risk discovery, remediation, policy, and compliance across cloud, on-prem, and hybrid environments).

I've been working in technology since 2012, with a decade-plus focus on:

- Cloud infrastructure (AWS, Azure, GCP)
- Infrastructure as code (Terraform, CloudFormation)
- Container orchestration (Kubernetes, Docker, K3s, BuildKit)
- CI/CD pipelines, platform engineering, and multi-tenant isolation
- Systems and tooling in Go, Python, TypeScript, and Zig

## Open source

Active builder across 160+ public repositories. Selected work:

- [Rexec](https://github.com/PipeOpsHQ/Rexec) — terminal control room / Terminal-as-a-Service (cloud sandboxes + BYOS agents)
- [OpenFing](https://github.com/9trocode/OpenFing) — privacy-first network scanner in Zig
- Firecracker and sandbox tooling, self-hosted observability experiments, and infra utilities

I ship tools that solve real problems and share them with the community.

## Writing

I write about infrastructure, automation, and production systems — architecture deep dives, open source tools, security and privacy tradeoffs, and lessons from incidents. Primary topics: **platform engineering** and **cloud-native security**.
